# ⚖️ LawMate — AI-Powered Legal Document Analyzer

LawMate is a Streamlit web app that uses Google Gemini AI to analyze legal documents and answer general law questions in plain English.

---

## 🚀 Features

- 📄 Upload PDF or TXT legal documents
- 🔍 Per-page AI analysis with summaries and key points
- 📘 Overall simplified document summary
- 💬 Ask questions about the document or general law (IPC, CrPC, etc.)
- ⚡ Smart routing — general law queries use AI knowledge, document queries use uploaded file
- 🔁 Auto-retry with exponential backoff on API rate limits
- 🌙 Dark-themed modern UI

---

## 🛠️ Tech Stack

| Tool | Purpose |
|------|---------|
| [Streamlit](https://streamlit.io/) | Web UI framework |
| [Google Gemini API](https://ai.google.dev/) | AI model (gemini-2.0-flash) |
| [PyPDF2](https://pypdf2.readthedocs.io/) | PDF text extraction |
| [pyngrok](https://pyngrok.readthedocs.io/) | Tunnel for Colab deployment |

## ▶️ Running on Google Colab

### Step 1 — Add Secrets
In Colab, click the 🔑 **key icon** in the left sidebar and add:

| Secret Name | Value |
|-------------|-------|
| `GEMINI_API_KEY` | Your [Google Gemini API key](https://aistudio.google.com/app/apikey) |
| `NGROK_TOKEN` | Your [ngrok auth token](https://dashboard.ngrok.com/get-started/your-authtoken) |

### Step 2 — Run All Cells
Run the notebook cells in order:
1. Install dependencies
2. Write `requirements.txt`
3. Set API key from secrets
4. Write `app.py`
5. Launch the app via ngrok tunnel

### Step 3 — Open the App
After running the last cell, a public URL like `https://xxxx.ngrok-free.app` will appear in the output. Click it to open LawMate.

## 💻 Running Locally (without Colab)

### Prerequisites
- Python 3.9+
- A Gemini API key

### Install dependencies
```bash
pip install streamlit google-genai PyPDF2 pyngrok
```

### Set your API key
```bash
# Windows
set GEMINI_API_KEY=your_key_here

# Mac/Linux
export GEMINI_API_KEY=your_key_here
```

### Run the app
```bash
streamlit run app.py
```

## 💡 How to Use

1. **Upload a document** — drag and drop a PDF or TXT file
2. **Click "Analyze Document"** — AI will summarize each page
3. **Read the overall summary** — plain English explanation of the document
4. **Ask questions** — type in the chat box:
   - *"What are the termination rights in this contract?"* → uses your document
   - *"What is IPC Section 420?"* → uses AI general knowledge
