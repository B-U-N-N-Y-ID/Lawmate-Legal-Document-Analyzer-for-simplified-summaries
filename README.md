# LawMate: AI-Powered Legal Document Analyzer

LawMate is an intelligent web application that simplifies complex legal documents using AI. It allows users to upload legal PDFs or text files, generate summaries, extract key points, and ask legal questions in simple language.

---

## Features

- Upload and analyze legal documents (PDF/TXT)
- AI-powered summarization of complex legal text
- Extraction of key points from each page
- Visual insights (summary length, key points, density)
- Ask questions about:
  - Uploaded documents
  - General legal concepts (e.g., IPC sections)
- Fast and interactive UI using Streamlit

---

## Tech Stack

- Frontend & Backend: Streamlit
- Programming Language: Python
- AI Model: Google Gemini API
- Libraries Used:
  - PyPDF2
  - Pandas
  - Matplotlib
  - Seaborn
